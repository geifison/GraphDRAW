# GraphDRAW
Editor de ilustração vetorial open source em Rust para gráficas rápidas, comunicação visual e corte em plotter/laser. Abre arquivos .cdr e .cmx legados, salva no formato aberto .gdr e exporta PDF (inclusive PDF/X-1a), SVG e PNG. Tem edição de nós, várias páginas, camadas, atalhos configuráveis e linha de comando para converter arquivos em lote.
