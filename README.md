# GraphDraw

Editor de ilustração vetorial **open source** para gráficas rápidas, comunicação visual e corte em plotter/laser.

- Abre arquivos `.cdr` legados (via [libcdr](https://wiki.documentfoundation.org/DLP/Libraries/libcdr))
- Formato nativo aberto e documentado: `.gdr` ([especificação](docs/spec/13-FORMATO-GDR.md))
- Exporta PDF/X, SVG, PNG, DXF, PLT/HPGL

> Status: pré-alfa — especificação pronta, implementação começando pelo marco M0.

## Procedência
Desenvolvido em sala limpa: o código é escrito exclusivamente a partir da especificação funcional em [`docs/spec/`](docs/spec/), sem acesso a código, binários ou ativos de terceiros. Ver [protocolo](docs/spec/00-PROTOCOLO-CLEANROOM.md) e [CONTRIBUTING](CONTRIBUTING.md).

GraphDraw não é afiliado a nenhum fabricante de software. Marcas citadas pertencem aos seus titulares e são usadas apenas para indicar compatibilidade de formatos.
