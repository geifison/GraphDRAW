# Format file

GraphDraw menyimpan dalam formatnya sendiri, `.gdr`, yang menyimpan semuanya,
dan juga menyimpan file `.cdr`. GraphDraw membuka dan mengimpor banyak format
lain, serta mengekspor format vektor, bitmap, dan cetak. Halaman-halaman ini
mencantumkan formatnya dan menjelaskan cara mengimpor, mengekspor, dan
menerbitkan file PDF.
