  (dados de caracterização FOGRA39L).
- Origem: pacote `colorprofiles` do CTAN, versão 20181105
  (https://ctan.org/pkg/colorprofiles), gerado por Peter Selinger com
  `cd-create-profile` (colord) a partir do XML do OpenICC.
