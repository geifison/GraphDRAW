# Contribuindo com o GraphDraw

## Regra de sala limpa
Ao contribuir, você declara que:
1. Escreveu a contribuição a partir da especificação (`docs/spec/`) e de conhecimento geral/público.
2. **Não** consultou código-fonte vazado, descompilação, desmontagem ou internos de software proprietário para escrevê-la.
3. Não incluiu ícones, imagens, textos ou outros ativos de terceiros sem licença compatível.

Commits devem ter `Signed-off-by:` ([DCO](https://developercertificate.org/)) — use `git commit -s`.

## Fluxo
- Abra uma issue citando o(s) ID(s) de requisito (`GD-XXX-NN`).
- PR com testes cobrindo o critério de aceitação.
- Requisito ambíguo → proponha mudança em `docs/spec/` em PR separado.

## Dependências
Somente licenças compatíveis com a do projeto. Registre em `THIRD_PARTY.md` (nome, versão, licença, uso).
